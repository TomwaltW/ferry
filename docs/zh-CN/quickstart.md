# 快速上手

[English](../en/quickstart.md) · **中文**

从一份干净的 clone 到 agent 在聊天窗口回你话，中间要做哪些事。目前只是提纲 ——
具体步骤随 P1 的微信入口和托管会话落地补充。

## 安装

下载二进制、`go install`、从源码构建。以及 Ferry 的数据目录放在哪
（环境变量 `FERRY_HOME`，默认 `~/.ferry`）。

## 登录

在终端扫登录二维码、确认登录后存了什么、怎么判断平台会话已经过期。P1 补充。

## 配对账号

把你自己的聊天账号变成这个守护进程的操作者，以及未配对的陌生人会看到什么。
P1 补充。

## 第一个会话

选 agent 预设和工作目录、发出第一个任务、读流式返回的回复。P1 补充。

等微信入口、agent 和接力几页有内容之后，从这里跳过去。
