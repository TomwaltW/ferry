# 微信入口

[English](../en/wechat.md) · **中文**

Ferry 怎么经 iLink 网关和微信打交道。目前只是提纲 —— 内容随 P1 补充，
回复窗口的实测数据随 P2 补充。

## 登录

扫码流程、bot token，以及会话进行到一半平台会话过期时会怎样。P1 补充。

## 配对与陌生人门控

谁有资格驱动会话、配对码怎么发怎么核销、未配对的发送者会收到什么回复。
P1 补充。

## 回复窗口

微信只允许 bot 在一条入站消息打开的窗口内回复。什么是回复上下文、它能活多久、
一个窗口能塞下几条回复。P1 人工验收时实测，P2 用这些数据。

## 投递与重试

发件箱怎么给重试的消息去重、窗口重开之前暂存什么、什么情况下丢弃。P2 补充。

## 附件

图片、文件和语音，包括哪些会下载到本地、哪些只留引用。P2 补充。
